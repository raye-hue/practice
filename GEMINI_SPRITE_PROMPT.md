# Gemini skill-sprite prompt for Sigma Showdown

Use this prompt in Gemini with the attached reference photo so the sprites match its style.

Create a cohesive 2D fighting-game sprite pack for Sigma Showdown. Use the attached photo as the style reference for line weight, shading, color palette, and overall vibe. Keep the art readable at small size, with bold silhouettes and consistent proportions across the whole roster.

Output requirements:
- One skill-sprite pack per character.
- Transparent PNGs.
- Keep the character centered with consistent scale.
- No text, borders, logos, or background scenery.
- Match the reference photo's style first, then preserve each character's identity.
- Make the sprites suitable for a side-view fighting game.
- Include these skill animations: idle, walk, jump, attack, hurt, ko.
- Also create 2 bonus poses for each character: taunt and victory.
- If possible, provide each animation as a horizontal sprite sheet with evenly sized frames.
- Keep lighting and line weight consistent within each character set.
- Make the attack and special poses look like distinct character skills, not just generic punches.
